Speakers

Pelino Uwase

Keynote: Internet of Things · 9:00am

IoT engineer and keynote speaker. Opens the day with a look at how JavaScript is powering connected devices.

James Carter

React Basics · 10:00am

Front-end engineer. Walks through components, props and state so you can ship your first React app.

Amina Diallo

Mongo! · 11:00am

Database advocate. Shows how to model, query and scale document data with MongoDB.

Intro: Node JS · 2:00pm

Babel · 4:00pm

Tooling maintainer. Explains how Babel compiles modern ES2015+ code so it runs everywhere today.
